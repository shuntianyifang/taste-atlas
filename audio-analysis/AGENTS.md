# 本地音乐分析约定

- 此目录为 Taste Atlas 音频实现，独立于博客前后端；Git 仓库位于项目根目录，不在此目录嵌套初始化，不提交模型、音频、虚拟环境或缓存。原创代码按根 LICENSE 使用 AGPL-3.0-only，第三方许可独立保留。
- 原 `.venv` / `audio.ps1` 使用 CLAP；MuQ 使用独立 `.venv-muq` / `compare_models.py`。修改一条路径不得隐式升级另一环境。
- Essentia 标签模型使用 `.venv-essentia` 和 `essentia_cli.py`，Windows ONNX CPU；`.reference-essentia-js` 用于前处理参考校验及新增 MELODIA 主旋律算法，不替换原标签模型的推理路径。
- 不修改、移动或上传用户音乐。仅模型准备脚本联网；推理使用本地权重，离线失败必须报错。
- 固定模型提交及依赖版本，验证文件完整性；保留第三方模型许可与署名。
- 对照必须使用相同来源和展示时段；CLAP/MuQ 共用词表，Essentia 保留官方固定标签，不强行合并置信度。记录各自采样率、精度、补齐、汇总方式与耗时。
- 相似度不是概率；跨模型分数大小、排名一致率都不是准确率。没有人工标注时不宣称哪个模型更准确。
- 修改后运行相关自测、依赖检查和必要真实音乐推理；未完成下载或推理不能标记验收通过。
- `deep_cli.py` 使用独立 `.venv-deep` 顺序运行结构／和声、HTDemucs 分离、音高图与试听副本；不要升级或修改原三个环境。固定依赖见 `requirements-deep.lock.txt`。
- 结构仅输出变化边界和同速相似片段候选；三和弦／调性模板和 pYIN 不是准确乐谱。分离 vocals 槽位不证明有人声，不用重构残差宣称声部纯度。
- 分离前核对原文件及解码文件 SHA-256、声道、采样率和实际时间范围；固定官方模型完整摘要校验成功后才能加载旧式 checkpoint。任何失败不能写分离完成状态。
- 原始声场／响度使用原采样率、原声道浮点副本；浏览器 PCM16 副本单独标记，所有声部使用共同增益。分析与试听不能混淆。
- 浏览器崩溃或未完成播放／导出验收必须写明；CLI 校验通过不能替代实际浏览器验收。只使用回环试听服务，不上传音乐。
- 试听使用 `player_controls.js` 自定义控件，避免重新引入已复现崩溃的原生 media controls。切轨须保留时间和播放意图；生成 HTML 后重新做浏览器验收。标记保存仅接受同源回环请求，限制结构、大小和输出目录；验收标记不代表用户喜好。
- MELODIA 使用锁定 Essentia.js 0.1.3 官方 WASM、等响度预处理和默认参数，保留原生 pitchConfidence、静音零值和实际帧时间；合成音仅用于核对轮廓。候选覆盖率不能称为准确率。
